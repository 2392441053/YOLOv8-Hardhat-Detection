# 👷 基于 YOLOv8 的工地安全帽佩戴检测系统

本项目基于 YOLOv8 目标检测算法，针对工地场景构建了安全帽佩戴检测系统。通过对官方预训练模型进行迁移学习（微调），实现了从数据工程、模型训练到 Web 端可视化部署的全流程落地。

## 🌟 核心功能
- **高精度检测**：精准识别“佩戴安全帽 (`Hard-hat`)”与“未佩戴安全帽 (`NO-Hard-hat`)”两类目标。
- **动态阈值调节**：前端支持滑动条调节置信度阈值（Confidence Threshold），平衡漏检与误检。
- **轻量级部署**：模型大小仅 6.5MB，在 CPU 环境下单图推理仅需 **26.7ms**，满足实时检测需求。

## 🛠️ 技术栈
- **算法框架**：YOLOv8, PyTorch
- **数据处理**：OpenCV, YOLO 格式数据集转换
- **前端交互**：Gradio

## 📊 模型指标
在 8000 张验证集上的评估表现：
- **mAP@0.5**：76.1%
- **单图推理速度**：26.7ms
